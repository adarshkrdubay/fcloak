# Code of Conduct

## Our standard

We want FCLOAK development to remain respectful, technical, constructive, and welcoming.

Contributors should:

- Be respectful.
- Focus criticism on ideas and code.
- Accept constructive feedback.
- Avoid harassment or discrimination.
- Keep security discussions responsible.
- Protect other users' privacy.

## Unacceptable behavior

Examples include:

- Harassment
- Threats
- Discrimination
- Deliberate exposure of private information
- Malicious behavior toward contributors or users

Project maintainers may remove contributions or restrict participation when necessary to keep the project healthy.

## Security issues

Do not use public issues to disclose sensitive vulnerabilities before the maintainer has had an opportunity to assess them.
