FCLOAK

A local-first encrypted desktop vault with optional cloud storage.

Download Alpha View source

Encrypt first. Store second.

Local encryption

Files are encrypted locally into .fcloak containers.

Cloud storage

Encrypted containers can be synchronized with supported cloud providers.

Local restore

Downloaded containers are decrypted and exported locally.

Cloud providers

Google Drive — Alpha 1
Microsoft OneDrive — Planned
Dropbox — Planned
S3 / WebDAV — Planned

Security notice

FCLOAK Alpha 1 has not received an independent security audit. Do not rely on it as the sole protection for irreplaceable or highly sensitive information. Keep independent backups.
